# پرامپت‌های میکروتیک

![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)
![RouterOS](https://img.shields.io/badge/RouterOS-v7-red.svg)
![Tested](https://img.shields.io/badge/tested-real%20hardware-success)

مجموعه‌ای از پرامپت‌های تست‌شده برای پیکربندی روترهای میکروتیک در سناریوهای رایج و واقعی.

هر پرامپت به‌گونه‌ای نوشته شده که به یک ابزار خاص وابسته نباشد؛ می‌توانید آن را به Claude،
Codex، Qwen یا هر ایجنت هوش مصنوعی توانمند دیگری که به روتر شما دسترسی SSH دارد بدهید تا
روند پیکربندی را پیش ببرد، هر چه لازم دارد بپرسد و تنظیمات را با احتیاط اعمال کند.

> **📌 مهم**
>
> این پرامپت‌ها یک ابزار کمکی برای کسانی است که **میکروتیک و پایهٔ شبکه را بلدند** و کاری را که
> خودشان از پسش برمی‌آیند سریع‌تر و کم‌ریسک‌تر می‌کند؛ نه ابزارِ «صفر تا صد» و نه معجزه. شبکه را
> به شما یاد نمی‌دهد. همیشه قبل از تأیید، نقشهٔ کار ایجنت را نگاه کنید و README و بخش ملاحظات را
> بخوانید.

## نحوهٔ استفاده

۱. پوشهٔ همان پرامپت را باز کنید و README آن را بخوانید.

۲. کل فایل `prompt.md` را کپی کنید و به ایجنت هوش مصنوعی خود بدهید.

۳. بخش `CONFIG` در انتهای پرامپت را با اطلاعاتی که دارید پر کنید (آدرس روترها، نام کاربری و
   رمز، ترجیح‌ها). هر چه را خالی بگذارید، ایجنت در حین کار از شما می‌پرسد.

۴. اجازه دهید ایجنت بررسی‌های اولیه را انجام دهد (ابتدا از پیکربندی نسخهٔ پشتیبان می‌گیرد) و
   نقشهٔ کارش را تأیید کنید.
